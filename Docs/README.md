## 💻 COMANDI RAPIDI

```bash
# Avvio sistema
cd backend && npm run dev  # Backend
cd .. && npm run dev       # Frontend

# Database
cd backend
npx prisma studio          # GUI database
npx prisma migrate dev     # Migrazioni
npm run seed               # Popola database

# Git
git add -A
git commit -m "descrizione"
git push origin main
```
